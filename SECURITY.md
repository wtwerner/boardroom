# Security

Boardroom holds a group's Discord sign-ins and bot token, so please don't open a public issue for a security problem. Report it privately from the repo's **Security** tab (**Report a vulnerability**), with what you found and how to reproduce it. You'll hear back within a week.

Each group runs its own copy, so a fix reaches a group when it pulls the change in ([Updating](README.md#updating)). Fixes go to `main`; there are no older versions kept up to date.
